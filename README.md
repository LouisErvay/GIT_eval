# Evaluation GIT - 2025/09/30

## Projet GIT :

Le projet `GIT` contient deux parties :

- `core` qui représente le backend, fait en Python fastAPI avec Uvicorn.
- `front` qui représente le frontend, fait en vite, react et typescript.

## Première initialisation :

### Core

Vous devez au préalable avoir python d'installé sur votre machine

- Ouvrir un terminal à la racine du projet
- Déplacement dans le bon fichier :  
  `cd core`
- Initialisation d'un environement python :  
  `python -m venv .venv`
- Activation du venv :  
  `.\.venv\Scripts\activate`
